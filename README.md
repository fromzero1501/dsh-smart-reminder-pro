# dsh-smart-reminder 智能提醒与农历日历助手

DSH Web GUI 通用智能提醒、农历日历看板与待办清单助手插件。

[English Documentation](./README.en.md) | [Documentación en Español](./README.es.md)

## 关于本仓库（Pro 版增强）

**dsh-smart-reminder-pro** 是上游 [dsh-smart-reminder](https://github.com/a792883583/dsh-smart-reminder)（MIT，作者 Jaden Tang）的功能增强分支。原有能力全部保留（顶部速记栏、农历、拖拽改期、5 秒撤销、.ics 导出、系统通知、Agent 工具、平台推送），只重做日历格子的版式与节日数据：

- **格子版式**：去掉卡片边框与底色，日期数字 13px → 27px 并居中；周末数字红色；非当月日期淡化；待办角标与完成勾移到右上角；7 列 6 行等宽等高，内容撑不开格子。
- **今天与选中**：今天整格红底（#c62f2f）白字，红底铺满整格（含边框位置）、圆角与格子同；手动选中为 **2px 红框 + 淡红底**；今天且选中 = 红底 + 白色内描边。
- **副标题三色**：节日红字、二十四节气绿字、数九三伏深灰、普通农历日灰。节日与节气撞同一天时**两行都显示**（如 2026-06-21「父亲节 / 夏至」）。
- **二十四节气全量**：内置节气计算（太阳视黄经低精度算法，1900–2100 有效；个别年份可能相差一天，范围外不显示）。
- **节日表**：按参考万年历收录，公历 33 条、农历 15 条（含财神节、尾牙、北方/南方小年、按当年大小月现算的除夕）、浮动 3 条（母亲节、父亲节、感恩节），另加节气锚定节日（丰收节=秋分、春社日=立春后第 5 个戊日）。
- **数九与三伏**：冬至起每九天一个九（一九…九九）；初伏 = 夏至后第 3 个庚日，末伏 = 立秋后第 1 个庚日，出伏 = 末伏后第 10 天（日柱干支算法以 2026-11-02 庚辰校准）。
- **法定节假日角标**：左上角显示「休」（放假）或「班」（调休上班）。调休安排每年由国务院公布、无算法，因此只内置 **2026 年** 放假表（`src/core/statutory.ts`），其他年份不显示角标。
- **不变的部分**：host 侧 API、reminders.json 存储、调度与漏发补发、Toast 通知、5 个 Agent 工具、侧栏按钮挂载逻辑均未改动。

### 构建与本地覆盖

```bash
pnpm install
pnpm build     # 产出 lib/index.js（host）+ lib/client.js（浏览器端 bundle）
```

包名保持 `dsh-smart-reminder`，构建产物可直接覆盖 profile 里 `node_modules/dsh-smart-reminder` 的同名插件后重启 DSH。

## 功能特性

1. **顶部常驻闪电速记栏 (Natural Language Quick Add)**：
   - ⚡ 顶部常驻单行极简速记输入栏，支持纯自然语言输入（如「明早10点研发周会」、「周五下午5点交周报」、「30分钟后看烤箱」或「tomorrow 3pm review」），敲 Enter 瞬间智能提取标题与精确时间完成待办创建，零多余点击！
2. **周期循环提醒与自动顺延流转 (Recurring Tasks)**：
   - 🔂 支持每天、每周、每月等周期循环；清单中点击打勾完成当前事项时，系统自动顺延计算并无缝生成下一个周期的待办事项，无需重复手工录入。
3. **左侧导航专属入口**：内嵌于侧边栏「工作区」行、紧贴搜索图标左侧，与官方的搜索 / 视图 / 添加图标排成一行；宽栏与收起态分别对齐官方 28px / 36px 圆形图标规格，悬停带样式化提示。
4. **系统原生桌面通知**：
   - 🔔 深度打通 macOS 原生系统通知横幅，精准伴随清脆玻璃提示音（Glass），锁屏与后台全场景准时弹出。
   - 🪟 深度打通 Windows 10/11 原生 Toast 强提醒通知（`scenario="reminder"` + `Priority=High`），即使在「专注助手 / 仅优先通知」环境下也能在屏幕右下角即时浮现弹窗卡片并播放提醒音效。
3. **拖拽改期 (Drag & Drop)**：
   - 🖱️ 支持鼠标直接按住右侧日程卡片，拖拽至左侧日历任意日期格释放，瞬间将事项改期至目标日期！
4. **快捷原位编辑 (In-Place Edit)**：
   - ✏️ 事项卡片提供编辑按钮，点击唤出预填表单，可随时修改标题、时间点、推送渠道、优先级与备注。
5. **深度国际化 (中 / 英 / 西)**：
   - 完美适配 **中文 (zh)**、**英语 (en)**、**西班牙语 (es)**，100% 自动实时跟随 DSH Web 当前语言环境，零闪烁。
   - 节日自适应：中文展示完整农历与民俗节气；英西展示公共法定节日（圣诞、万圣、元旦等）。
6. **待办 Checklist 打勾与状态筛选**：
   - 支持圆角复选框一键打勾完成与自动划线归档。
   - 顶部提供 `全部` / `待办` / `已完成` 快速胶囊筛选。
   - 🔍 即时关键词搜索，支持实时匹配标题与备注。
7. **消息网关插件生态联动**：
   - 自动检测并联动 [`dsh-message-gateway`](https://www.npmjs.com/package/dsh-message-gateway) 插件。
   - 支持一键配置 **企业微信 (WeCom)**、**Telegram**、**Discord** 或 **邮件** 协同推送，未安装时提供友好引导。
8. **一键推迟（Snooze）与 5秒撤销（Undo）**：
   - 事项卡片支持快捷一键 `+15m`、`+1h` 延后重新提醒。
   - 删除事项后底部提供 5 秒一键撤销（Undo），杜绝误触。
9. **离线漏发补发（Catch-up）**：
   - 电脑休眠/关机唤醒后自动检测逾期并弹出汇总横幅，支持一键全部完成。
10. **标准 iCal (.ics) 日历导出**：
    - 一键下载 `.ics` 文件，可直接双击导入 Apple 日历、Google Calendar 与 Outlook。
11. **全键盘快捷键**：
    - `Esc`：关闭看板或弹窗；
    - `Cmd/Ctrl + K`：呼出新建提醒；
    - `← / →`：快捷切换上月 / 下月。

## Agent 工具列表

- `set_reminder(title, dueTime, description?, repeat?, pushPlatform?, pushTarget?)`: 设定定时提醒与周期循环。
- `list_reminders(type?: "upcoming" | "history" | "all")`: 查询未来待触发与历史归档提醒。
- `complete_reminder(id)`: 智能体执行后自动打勾完成或恢复。
- `snooze_reminder(id, minutes?)`: 智能体根据对话推迟提醒。
- `cancel_reminder(id)`: 撤销取消指定提醒。
